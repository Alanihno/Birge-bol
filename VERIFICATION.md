## Границы проверки

- Браузерный сценарий выполнен на локальном production preview в явном деморежиме. Живые Supabase REST/RPC/RLS проверялись отдельно; получение настоящего email magic link и полное удаление вошедшего Auth-пользователя не выполнялись.
- Нет настоящего Gemini ключа, отправки Telegram, настоящего бронирования и подтверждённых посещений. Для Telegram это закрытые заглушки; для словаря есть локальный fallback.
- Vercel API вернул 403 для подключённой команды. Сайт на Vercel не развёрнут; SPA refresh проверен локально, фактические production rewrites/Auth Redirect/CORS нужно проверить после импорта.
- PWA проверена в Chrome, без фактического нажатия установки на Android/iOS. Инструкции для браузеров есть в настройках.
- Lighthouse, нагрузочный тест, полноценная ручная проверка скринридером, независимый security audit и юридическая оценка не выполнялись. Их результаты не заявляются.
- Установщик сообщил о deprecated glob/ESLint; Rollup удаляет неинтерпретируемые PURE-комментарии Zod. Сборка завершилась успешно. Проверка advisors относится к БД и не означает отсутствия всех рисков в зависимостях/продукте.
- Среда блокировала прямое npm-соединение EACCES. Установка завершена через кэш и чтение публичных npm-архивов доступным инструментом; npm проверял integrity. Временный HTTP extension создавался только внутри откатываемых транзакций, установочный мост остановлен. Lockfile использует обычный https://registry.npmjs.org, без локального прокси.
