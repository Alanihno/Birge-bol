## Что изменено

- Палитра EB0032 / 4B0073 / C8AAFF / E6E1FF, компактные карточки и мобильная навигация. SVG-маскот «Бірге» встроен в существующего помощника, лендинг, cookies, пустые состояния и ошибки; отдельной ИИ-модели у него нет.

- Локальные поисковые подсказки, районы, стабильное управление картой, 2ГИС; математический рейтинг без выдуманной оценки для профиля без собственных отзывов; разделение демо- и реальных отзывов.

- Проверенные YouTube URL, просмотр после согласия, назначения/дневник и отзыв доступа; журнал событий согласий.
- Внутренние уведомления и программная часть Web Push: устройства, частная очередь, напоминания, серверная отправка. Нейтральный текст на заблокированном экране.

## Supabase и предупреждение о паролях

Применены пять добавочных миграций `20261117083631`–`20261117093353`, копии сохранены в `supabase/migrations`. Развёрнуты explain v4, translate-message v6 и push-dispatch v1. RLS/проверки полномочий защищают данные независимо от клиентских экранов.

Последний security advisor возвращает один WARN: **Leaked Password Protection Disabled**. Это сообщение об отключённой настройке, а не доказательство произошедшей утечки. Текущий проект — Free; встроенная серверная проверка требует Pro. Бесплатная проверка форм уже работает, но обходится прямым Auth API и не заменяет встроенную защиту. Платный тариф не подключался. [Официальные условия Supabase](https://supabase.com/docs/guides/auth/password-security#password-strength-and-leaked-password-protection).

Сканирование 125 файлов connected-сборки по шаблонам private keys, service_role JWT, sb_secret и Gemini keys совпадений не обнаружило. Это ограниченная проверка артефактов, не независимый аудит и не доказательство отсутствия любых инцидентов.

## Открытые внешние условия

- Встроенная серверная защита Supabase от утёкших паролей: требуется Pro и включение настройки владельцем.
- SMTP, Auth redirect allowlist и реальное получение писем. Подготовлены шаблоны; доставка и recovery на реальном почтовом ящике не заявляются проверенными.
- VAPID, PUSH_CRON_SECRET и расписание отправки: доступный коннектор не управляет Edge secrets. Настроек нет, интерфейс честно сообщает недоступность Push. Реальные Android/iOS устройства не проверены.
- Утверждение юридического оператора, контактов, сроков хранения, прав на материалы, медицинских текстов и размещения данных. Текущий Supabase — ap-southeast-2; тексты юридических страниц являются проектами.
- Чистый db reset, восстановление backup и независимая установка: CLI не установлен, загрузка npm ограничена, Docker daemon недоступен. Непроверенная миграция всей истории на пустую БД не объявляется успешной.
- Lighthouse недоступен в среде. Числа Performance/Accessibility/SEO/LCP/CLS/TBT не выдумывались. Общий объём новых функций вырос; уменьшение основного demo JS отражено в реальных метриках, все показатели быстрее не объявляются.
