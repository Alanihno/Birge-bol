# Загрузка демо на Vercel

1. Откройте https://vercel.com/drop и войдите в свой Vercel.
2. Перетащите папку «деплой версель» целиком (внутри сверху лежит index.html).
3. Выберите команду, имя проекта и нажмите Deploy.
4. Откройте выданный HTTPS-адрес. «Начать бесплатно» → тестовая почта родителя, специалиста или клиники. Вход немедленный, проверять письмо не нужно.

Это готовые статические файлы. Не задавайте Framework=Vite, Build Command=npm run build или Output Directory=dist: в этой папке сборка уже выполнена. Ключи, npm install, Supabase и Git для этой загрузки не нужны. vercel.json содержит переходы SPA, заголовки и CSP.

Vercel Drop: официальное описание https://vercel.com/changelog/vercel-drop . Каждый Drop создаёт новый проект; для последующего автоматического обновления можно подключить Git.

После загрузки проверьте открытие /find, обновление /specialists/00000000-0000-4000-8000-000000000001, /manifest.webmanifest и /sw.js. Установка PWA: Android/Chrome — меню установки; iPhone/Safari — «Поделиться» → «На экран Домой».

Установку запускайте на опубликованном HTTPS-адресе в отдельной обычной вкладке. ZIP/локальный index.html, встроенный браузер Telegram/Instagram, iframe предпросмотра и инкогнито могут не предоставлять установку. Если в приложении нет кнопки, используйте меню браузера: это не равнозначно запрету установки. В обновлённой версии приглашение к установке запоминается с главного экрана и не теряется при переходе в настройки. Уже открытая старая PWA обновляется через «Настройки» → «Есть обновление — перезагрузить».

Что отключено и как обращаться с данными — в «СТАТУС ДЕМО.md» и разделах приложения «Конфиденциальность»/«Условия». Для показа используйте вымышленные сведения.
