# Birge Bol — план реализации

React + Vite + TypeScript, React Router, TanStack Query, Tailwind, исходные доступные UI-компоненты, React Hook Form/Zod. Static dist для Vercel, PWA с кэшированием только статики. Supabase Auth/Postgres/RLS и два явно разделённых адаптера.

Сквозной MVP: welcome → анкета → объяснимые правила → каталог/карта → специалист/избранное → вопрос мамам → чек-лист/черновик → дневник/цели/синтетическое аудио → словарь. Дополнительно: настройки, уведомления, защищённая админка, правовые черновики, 404.

Данные: 24 вымышленных специалиста Астаны, 25 терминов, синтетические вопросы/отзывы. DEMO — локальные тестовые данные с явным входом; Supabase — только реальные ответы API, без скрытого fallback. В браузере только публичные URL/anon. Роли назначаются SQL администратором, приватные таблицы ограничены auth.uid().

P0: полноценные локальные сценарии, адаптивность 320–1440, deterministic rules/reviews, тесты, production PWA. P1: подключённая SQL схема, Auth, сохранение личных данных, модерация, optional Edge Functions. P2: настоящая запись/слоты, push, OCR, загрузка детского голоса, кабинет специалиста.

Privacy: использовать только вымышленные профили; не загружать документы/голос. До реального пилота обязательны независимая юридическая проверка Казахстана, локализация данных, клинический review словаря/правил и security audit. Согласие не заменяет эти проверки.

Проверки: typecheck, lint, unit tests, build, browser smoke по основному сценарию, manifest/SW, мобильный overflow, RLS A/B и запрет повышения роли. Реальные результаты фиксируются в VERIFICATION.md.
